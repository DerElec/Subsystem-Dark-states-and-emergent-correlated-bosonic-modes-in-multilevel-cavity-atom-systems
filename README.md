# paper-template
This repository contains some inspirations on how to structure the paper-repository.

This layout essentially includes: 

- 001_TeX: TeX-files potentially accessed via Overleaf.
- 002_Figures: Finished figures of the manuscript.
- 003_Code: Code and Data related to the manuscript. Possibly with additional code documentation.
- 004_Tests: (Usually private) tests of the framework.
- 005_Communications: Private folder for submissions and communications with the journal/referees in the publishing process.

Note: Feel free to use, adapt, discuss and contribute to templates like this one.
